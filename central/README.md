# 中央 Agent 审核

中央 Agent 每轮读取 agent-a、agent-b、agent-c 三个远程分支中的明确提交和资料，先汇总发现再派发任务。

按 `Q01/round-001/` 保存：

- `review.md`：官方结果比较、关键发现、证据与冲突。
- `tasks.md`：A、B、C 下一轮自包含任务，包括起点版本、假设、改动范围、验证方式与结束条件。
- `baseline.md`：共同基线的准确版本和官方验收证据。

仅有可比较的有效官方结果才能支持性能排名和基线更新。组合方案单独实施和验证，不直接推定收益叠加。

本目录的共同记录由中央审核后更新；初始化说明不代表已有任何实验或验收结果。

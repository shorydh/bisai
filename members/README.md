# 成员接入

请使用本人 GitHub 账号提交“团队加入申请”Issue，并选择团队分配的 A、B 或 C 代号。

申请入口：https://github.com/shorydh/bisai/issues/new/choose

仓库所有者根据 Issue 作者账号核对身份并发送协作者邀请。申请者接受邀请后才获得相应写入权限；公开仓库的读取权限不等于写入权限。

接入回执只需提供：GitHub 用户名、执行者代号、加入申请 Issue 链接、仓库是否成功读取。

获得权限后分别使用 agent-a、agent-b、agent-c 分支。不要在本目录公开密码、访问令牌或不必要的个人资料。

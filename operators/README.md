# 实验交接

每轮按 `Q01/round-001/A/` 保存资料，题目、轮次与代号按实际替换。

- `summary.md`：本轮目标、假设与改动、实验结果、发现、最佳有效版本和下一步建议。
- `experiments.jsonl`：每行一项实验，至少包含实验编号、准确代码版本、官方任务编号或结果链接、官方状态与实际指标、相对官方基线的比较、结论与证据位置。
- `artifacts/`：可公开的源码快照、差异、日志和官方评测证据；若源码位于其他仓库，记录可访问的准确提交和路径。

每个可评测的实验版本在官方提交环境测试，获得结果后汇总。云环境分析只用于解释，不替代官方结果；失败与退化也保留。无法完成的实验说明原因，不造数。

每名执行者推送自己的分支后，交接分支名、提交编号和资料路径。中央 Agent 按明确提交审阅。
